

Este repositório contém o projeto desenvolvido durante o aprendizado flutter, no qual me concentrei em construir um aplicativo funcional com foco em navegação, temas e interação de componentes.

O objetivo do aplicativo é aplicar conceitos de UI/UX no Flutter, entender melhor o roteamento entre telas e explorar como personalizar widgets para criar uma experiência consistente entre Android e iOS.

🚀 O que foi implementado?

Botões personalizados

Criação de um botão customizado.

Ação para retornar à tela anterior.

(Cards)

Criação de cards interativos.

Possibilidade de percorrer/rolar cards.

Aproveitamento do comportamento herdado dos widgets.

Gestos (Gestures)

Implementação de retorno por gestos naturais.

Exemplo: deslizar para voltar.

Temas e cores dinâmicas

Alteração do esquema de cores do app.

Impacto visual em carts, barra superior e botão flutuante.

Uso da semente de cor inicial para definir todo o estilo.

Navegação (Routing)

Criação de pilha de telas.

Uso do roteador nativo do Flutter.

Introdução ao Go_router para facilitar navegação avançada.

🎯 Objetivos de aprendizado

Criar interfaces modernas com widgets customizados.

Entender o funcionamento do roteamento e pilha de telas.

Aprender a aplicar gestos e interações naturais.

Trabalhar com temas dinâmicos no Flutter.
